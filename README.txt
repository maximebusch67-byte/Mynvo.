🎮 EXTENSION MYNVO - SUBWAY SURFERS ZQSD

INSTALLATION RAPIDE :

1. 📥 Téléchargez ce fichier ZIP
2. 📂 Décompressez le dossier "mynvo-extension"
3. 🌐 Allez sur chrome://extensions/
4. 🔧 Activez le "Mode développeur" (en haut à droite)
5. 📁 Cliquez sur "Charger l'extension non empaquetée"
6. 🎯 Sélectionnez le dossier "mynvo-extension"
7. ✅ C'est fait ! L'extension est installée
